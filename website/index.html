Mavrick / Architecture

Guarantees Pipeline Platforms

Mavrick, in five guarantees.

  1. 01

    Instant Router

    Deterministic local launch, AST math, and saved /workflows resolve in under 0.1 ms (0.039 ms multi-app lookup) with zero LLM latency.

  2. 02

    Mechanical Policy

    Every action and multi-step plan passes strict schema allowlists (25 typed tools) and 4-tier risk scoring. Destructive actions lock initial focus on Cancel.

  3. 03

    Inode-Pinned Batch Undo

    File moves walk O_NOFOLLOW parents, commit to an fsync-backed journal, and roll back batches in reverse order via atomic no-replace rename, preserving conflicts.

  4. 04

    Multi-Provider Freedom

    Zero lock-in: switch between local Ollama, Groq, Cerebras, OpenRouter, custom OpenAI-compatible endpoints, or agy, with host-scoped keys and secret redaction.

  5. 05

    Dual-Era MCP & Cross-Platform Core

    Consent-gated 2026-07-28 discovery and legacy stdio MCP run on Linux, Windows, and macOS with zero third-party Python dependencies.

Get Mavrick

Linux desktop

Debian package

Installs the GTK 3 launcher and the mavrickd user service. Run from the directory containing the package.

sudo apt install ./mavrick_2.0.0_all.deb

Linux / macOS / Windows

Python wheel

Run from the directory containing the built wheel. The CLI uses Python 3.10+ and has zero pip dependencies.

python -m pip install ./mavrick-2.0.0-py3-none-any.whl

After installation

Setup

Choose a provider and configure local preferences.

mavrick --setup
